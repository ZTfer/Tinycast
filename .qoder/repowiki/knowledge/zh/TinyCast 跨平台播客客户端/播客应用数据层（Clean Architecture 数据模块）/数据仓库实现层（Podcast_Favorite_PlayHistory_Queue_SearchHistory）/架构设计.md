本模块按职责拆分为五个独立的仓库实现类，均实现 domain 层定义的 Repository 接口：
- `PodcastRepositoryImpl`：最复杂的仓库，组合 RemotePodcastDataSource、LocalPodcastDataSource、FileStorageService、FeedRefreshService，通过 PodcastMapper/EpisodeMapper 在 Model 与 Domain Entity 之间转换，并维护 `_itunesSearchFutures` 缓存 iTunes 搜索任务。
- `FavoriteRepositoryImpl`、`QueueRepositoryImpl`：薄封装，直接委托给对应的 Local*DataSource，仅添加日志记录。
- `PlayHistoryRepositoryImpl`：非接口实现类，直接操作 Isar 的 PlayHistory 模型，作为播放进度的唯一数据源，提供 find-by-episodeId/GUID/iTunesId 的多键查找逻辑。
- `SearchHistoryRepositoryImpl`：基于 Isar 的 SearchHistoryModel 实现关键词搜索历史的增删查。
依赖方向单向向下：仓库 → datasources/local_*datasource.dart + services/*service.dart + database/isar_service.dart + mappers/*_mapper.dart，不反向依赖上层 domain 的实现细节，仅依赖 domain entities 和 repository 接口定义。
