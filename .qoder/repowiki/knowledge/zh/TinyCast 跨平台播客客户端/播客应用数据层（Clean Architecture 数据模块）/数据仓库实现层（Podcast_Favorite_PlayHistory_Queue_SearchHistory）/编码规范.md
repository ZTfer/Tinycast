- 仓库类通过构造函数注入依赖并提供默认实例（如 dataSource ?? LocalXxxDataSource()），便于单元测试时替换为 mock。
- 所有异步方法统一使用 Logger.info/debug/warning/error 记录调用入口与关键步骤，日志前缀采用 `[MODULE-REPO]` 格式便于过滤。
- 对 Isar 写操作一律包裹在 `isar.writeTxn(() async { ... })` 事务中，保证数据一致性。
- 从 Model 到 Domain Entity 的转换统一通过对应 Mapper 类（PodcastMapper.toEntity、EpisodeMapper.toEntityList）完成，避免在仓库内直接映射字段。
- 异常处理采用 try/catch 捕获后抛出 AppException.unknown，保留原始 error 和 stackTrace，业务校验错误则抛出 AppException.validation。
- 多标识符查找（episodeId / episodeGuid / episodeITunesId）采用优先顺序 fallback 模式：iTunesId → GUID → 整数 ID，并在可选参数中以 `{String? xxx}` 形式传递。
