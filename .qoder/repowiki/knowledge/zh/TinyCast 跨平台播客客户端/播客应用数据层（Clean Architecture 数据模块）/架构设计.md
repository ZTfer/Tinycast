本模块遵循 Clean Architecture 的数据分层，形成单向依赖链：services → repositories → datasources → database/models。
- `models/` 定义 Isar 持久化模型（含 `.g.dart` 生成代码），由 `database/isar_service.dart` 单例统一管理数据库生命周期与版本。
- `datasources/` 按本地（Isar）与远程（Supabase/Dio）拆分数据源，每个领域（播客、收藏、队列、播放历史）都有对应的 local_* 与 remote_* 实现。
- `repositories/` 实现 domain 层定义的 Repository 接口，组合多个 datasource 与 file_storage_service，负责数据一致性、缓存策略与异常转换。
- `mappers/` 提供 Model ↔ Entity 的双向转换，隔离持久化结构与领域实体。
- `services/` 是数据层内的业务编排服务（下载、播放、RSS 解析、搜索、设置等），依赖 repositories 与 datasources 完成跨数据源的复杂流程。
- 启动时通过 `IsarService.instance.open()` 初始化数据库，所有仓库与服务通过依赖注入或单例获取实例。
