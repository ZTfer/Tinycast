- UI 组件统一以 StatelessWidget 或 ConsumerWidget 形式实现，通过构造函数接收可选的 domain 实体（Episode? / Podcast?），避免在组件内自行获取数据。
- 文本样式采用内联 TextStyle 定义，字号、字重、行高与颜色均以像素值直接指定（如 fontSize: 14, height: 20/14, color: Color(0xFF333333)），未使用主题变量。
- 跨组件交互通过 Riverpod 的 Provider 通知器完成（如 ShowInfo 中 ref.read(navigationProvider.notifier).showPodcastDetail），而非回调参数传递。
- 空值处理统一使用 ?? '' 或 null 检查后分支渲染占位符，确保组件在无数据时仍可正常显示。
