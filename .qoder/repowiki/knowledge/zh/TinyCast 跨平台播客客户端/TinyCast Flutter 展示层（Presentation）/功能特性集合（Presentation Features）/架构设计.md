本模块按业务 Feature 拆分子目录（home、library、search、subscribe、episode_detail、favorite、history、queue、downloads、settings、debug），每个子模块对外暴露一个顶层页面类（如 Downloads、Library、SearchPage、Settings 等），并通过 Flutter ConsumerWidget/ConsumerStatefulWidget 模式实现 UI 与状态分离。跨 Feature 的通信统一依赖三个基础设施：Riverpod Provider（数据源与加载状态）、PlaybackProvider（播放控制）、NavigationProvider（路由跳转）。所有页面均复用 presentation/widgets 下的通用组件（EpisodeItem、Skeleton、空状态页等），并通过各自子目录内的 widgets/ 存放仅本 Feature 使用的原子组件，形成「Feature 内聚 + 跨 Feature 共享」的分层结构。
