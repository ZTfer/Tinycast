该模块以 `library.dart` 中的 `Library` ConsumerStatefulWidget 作为入口，通过 Riverpod Provider（`podcastProvider`、`subscribedPodcastsProvider`、`latestEpisodesProvider` 等）订阅数据并驱动 UI。页面按功能拆分为多个子目录：`library_empty_page/` 处理无数据时的引导界面；`library_list_item/` 和 `library_episode_item/` 分别渲染单个播客条目及其最近集数；`library_show_info/` 提供可展开下拉菜单的节目信息卡片；`podcast_detail/` 则展示单播客的完整信息与剧集列表。UI 组件之间通过回调（VoidCallback）向上冒泡事件，业务逻辑（取消关注、下载管理、刷新）在 StatefulWidget 中直接调用 Repository 与 Service（如 `AudioDownloadService`、`PlayHistoryRepository`、`QueueRepositoryImpl`），并通过 `ref.invalidate(...)` 手动失效相关 Provider 以同步内存状态。导航通过 `navigationProvider` 和 `AppRouter` 完成，整体依赖方向为：UI → Riverpod Provider → data/repositories 与 data/services。
