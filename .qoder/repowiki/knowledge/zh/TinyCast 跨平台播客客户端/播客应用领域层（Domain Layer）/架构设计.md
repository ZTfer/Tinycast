模块严格遵循 Clean Architecture 三层划分：
- `entities/`：纯 Dart 数据类与枚举（Podcast、Episode、AppSettings、PlayHistory、QueueItem、SearchResult 等），全部使用 `final` 不可变字段 + 命名构造函数 + 可选默认值，并通过 `copyWith` 和 `toJson`/`fromJson` 提供不可变更新与序列化能力；枚举如 FeedRefreshInterval、AutoDownloadPolicy、SleepTimerOption 附带解析方法与默认回退。
- `repositories/`：以 `abstract class` 声明仓储契约（PodcastRepository、FavoriteRepository、QueueRepository、SearchHistoryRepository、PlayHistoryRepository），向上暴露领域操作（订阅/取消订阅、搜索、播放队列、收藏、历史记录），向下由 data 层实现；PodcastRepository 通过 `refreshPodcastFeed` / `refreshAllFeeds` 返回 `FeedRefreshResult` / `BatchRefreshResult`。
- `usecases/`：每个文件对应单一业务动作（如 GetPodcastByIdUseCase、AddToQueueUseCase），通过构造函数注入对应 Repository，在 `call()` 中执行参数校验（如正整数检查抛出 `ArgumentError`）与异常包装（捕获后统一转为 `Exception`），再委托给仓储。
依赖方向单向：usecases → repositories → entities，domain 层不反向依赖 data 或 presentation。
