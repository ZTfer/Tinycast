模块采用两层 C++ 抽象：`win32_window.h/.cpp` 提供 DPI 感知、主题同步、消息路由等通用 Win32 窗口基类；`flutter_window.h/.cpp` 继承该基类，封装 `flutter::DartProject` 与 `flutter::FlutterViewController` 以承载 Flutter 视图。入口 `main.cpp` 通过 `wWinMain` 初始化控制台/COM、构造项目参数、创建窗口并进入 `GetMessage` 消息循环。构建系统由两级 CMakeLists.txt 组成：顶层 `windows/CMakeLists.txt` 定义工程、编译标准（C++17、/W4 /WX）、Unicode 宏及安装规则，并通过 `add_subdirectory` 引入 `flutter/` 与 `runner/`；`runner/CMakeLists.txt` 声明可执行目标，链接 `flutter`、`flutter_wrapper_app`、`dwmapi.lib`，并依赖 `flutter_assemble` 以触发 Flutter 工具链生成插件注册代码。`flutter/` 目录由 Flutter 工具自动生成插件注册文件（`generated_plugin_registrant.*`、`generated_plugins.cmake`），不手动维护。
