模块以 `lib/main.dart` 为唯一入口，通过 `Platform.isIOS/Android` 分支区分移动端与桌面端：移动端直接运行 `MyAppMobile`，桌面端则先调用 `WindowUtils.initialize()` 并加载主题配置后，通过 `WindowController.fromCurrentEngine()` 读取 JSON 参数，按 `type` 分发到 `initMainWindow` / `initSettingsWindow` / `initSubscribeWindow` / `initEpisodeDetailWindow` 四个窗口初始化函数。`lib/multi_window.dart` 集中定义跨窗口通信的 `WindowArguments`（序列化/反序列化 Episode/Podcast 实体）以及各窗口的 `WidgetsApp` 根组件。`lib/window_utils.dart` 作为平台抽象层，通过 `export 'src/window_utils_native.dart'` 暴露 `WindowUtils` 和 `TitlebarSafeAreaWrapper`；`lib/src/window_utils_native.dart` 基于 `flutter_acrylic` 实现毛玻璃、透明背景、全屏内容等原生效果，`lib/src/window_utils_unsupported.dart` 提供空实现以保证非桌面平台编译通过。依赖方向单向向下：main → multi_window → window_utils → src/*_native.dart。
