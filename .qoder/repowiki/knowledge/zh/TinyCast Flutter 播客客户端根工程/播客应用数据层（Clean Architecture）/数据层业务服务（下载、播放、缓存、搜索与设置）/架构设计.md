该模块是 data/services 层，每个 .dart 文件对应一个单一职责的 Service 类，通过静态单例 `instance` 暴露（如 AudioDownloadService、FileStorageService、ImageCacheService、SettingsService），部分服务（RssParserService、ITunesSearchService、PodcastSearchService、FeedRefreshService）采用构造函数注入 Dio/DataSource 以便测试。
- 依赖方向：services → core/utils（Logger/AppException）、data/database（IsarService）、data/models（EpisodeModel/PodcastModel）、domain/entities（Podcast/Episode），不反向依赖上层。
- 核心协作关系：AudioDownloadService 依赖 FileStorageService 写磁盘、IsarService 持久化下载状态、ImageCacheService 拉取封面；CacheCleanupService 协调三者完成清理；FeedRefreshService 组合 Remote/Local DataSource 并通过 PodcastMapper/EpisodeMapper 做模型转换；PodcastSearchService 委托 RssParserService 解析 RSS。
- 事件机制：AudioDownloadService 通过 broadcast StreamController + globalEventStream 向 UI 推送 DownloadStatus/Progress 事件；AudioPlayerService 通过多个 StreamController 广播播放状态、进度、音量等。
- 并发控制：AudioDownloadService 内置 DownloadQueue（maxConcurrentDownloads=3）+ _activeDownloads Set 防止重复下载；FeedRefreshService 按 chunk 分批 Future.wait 控制并发刷新。
