本模块按数据源类型划分为三类独立类：
- 本地数据源：`LocalFavoriteDataSource`、`LocalPodcastDataSource`、`LocalQueueDataSource` 均通过构造函数注入 `IsarService`（默认走单例），基于 Isar ORM 对 favorites、podcasts、episodes、queues 等表进行 CRUD，并通过 `../models/*` 中的 Model 与 `../mappers/*` 在 Domain Entity 与持久化模型之间转换。
- 远程数据源：`RemotePodcastDataSource` 使用 Dio 发起 HTTP 请求，依赖 `RssParserService` 解析 RSS、`ITunesSearchService` 做 iTunes 元数据补全，并可回退到 `LocalPodcastDataSource` 做本地缓存；`RemoteSyncDataSource` 通过 `SupabaseService().client` 直接操作 Supabase 的 podcasts、episodes、user_podcast_subscriptions、playback_history、favorites、queue_items 等表。
- 依赖方向单向向下：datasources → core/utils（Logger、AppException）、core/services（SupabaseService）、data/database（IsarService）、data/services（RSS/ITunes 解析）、data/models/mappers，不反向依赖上层 domain 或 presentation。
