模块以 `base_provider.dart` 和 `base_state_notifier.dart` 为核心基础设施：`BaseProvider` 提供 `create/createAsync/createStream/createLazy` 静态工厂简化 Provider 构建；`BaseNotifier<T>`、`BaseListNotifier<T>`、`BasePaginatedNotifier<T>` 分别封装单值、列表、分页三类 `AsyncValue<T>` 状态机的 loading/data/error 生命周期与常用集合操作（addItem/removeItem/updateItem/clear），并配合 `PaginatedData<T>` 承载分页元数据。

每个业务领域一个独立文件（playback、queue、favorite、settings、feed_refresh、download、favorite_episodes、play_history、unplayed_episodes、navigation、podcast），统一采用 `NotifierProvider`/`AsyncNotifierProvider` + `State` 不可变对象 + `copyWith` 的模式。Provider 之间通过 `ref.read(...)` 或 `ref.watch(...)` 相互依赖，例如 `PlaybackNotifier` 依赖 `QueueNotifier`、`UnplayedEpisodesNotifier`、`SettingsProvider`、`SyncProvider` 等，形成由 UI 向 domain/repository 单向依赖的层次。

跨领域副作用集中在少数重型 Provider（如 `PlaybackNotifier` 监听 `AudioPlayerService` 的多个 Stream、定时保存进度、睡眠定时器）；其余 Provider 主要做薄封装，调用 domain usecase 或 repository 后刷新本地状态。
