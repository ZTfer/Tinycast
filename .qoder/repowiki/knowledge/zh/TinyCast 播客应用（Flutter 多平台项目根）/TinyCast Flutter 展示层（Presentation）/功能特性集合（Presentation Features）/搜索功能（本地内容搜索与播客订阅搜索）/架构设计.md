模块采用 Flutter + Riverpod 的 MVVM 分层：`search_page.dart` 作为入口 ConsumerStatefulWidget，根据 `SearchStatus`（initial/history/results/empty）动态渲染 SearchHistoryList、SearchResultsList 或 SearchResultsEmpty；状态管理由两个独立的 NotifierProvider 承担——`search_provider.dart` 中的 `SearchNotifier` 负责本地搜索与历史记录（依赖 domain 层的 UseCase 和 repository），`podcast_search_provider.dart` 中的 `PodcastSearchNotifier` 负责通过 PodcastSearchService/ITunesSearchService 进行远程播客搜索与订阅，并在订阅成功后触发自动下载策略。

UI 按职责拆分为子目录：`search_history/` 渲染历史条目列表，`search_results/` 下再分 episode/show/empty 三类结果视图，`search_toolbar/` 提供清空记录与快捷键提示。所有 UI 组件均为 ConsumerWidget/ConsumerStatefulWidget，通过 `ref.watch` 订阅对应的 Provider，通过 `ref.read(searchProvider.notifier)` 调用状态变更方法，实现单向数据流。

依赖方向严格向下：presentation → domain/usecases → data/repositories/services，并通过 `app_routes.dart` 进行页面跳转，避免反向依赖。
