- UI 组件统一使用 `ConsumerWidget` 或 `ConsumerStatefulWidget` 配合 `ref.watch` / `ref.read` 访问 Riverpod 状态，避免直接依赖全局变量。
- 异步操作后统一检查 `mounted` 再更新 UI 或通过 `ToastUtils` / `ErrorToast` 反馈错误，保证 Widget 销毁后不触发 setState。
- 取消关注等复杂业务流程采用分步 Logger.info 日志标记步骤（如「步骤 1/5」），并在 catch 块中记录 stackTrace 以便排查。
- 组件间通过构造函数参数传递回调（onTap、onUnfollow、onRemoveDownloads 等 VoidCallback），保持单向数据流与松耦合。
- 列表项使用 `ValueKey(podcast.id)` 作为 key，确保 ListView 重建时正确复用条目。
