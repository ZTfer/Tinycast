模块严格遵循 Clean Architecture 的三层划分：
- `entities/`：纯 Dart 数据类与枚举，如 Podcast、Episode、SearchResult、AppSettings 及其子枚举（FeedRefreshInterval、AutoDownloadPolicy、SleepTimerOption），仅包含不可变字段、构造函数、`copyWith`、`toJson`/`fromJson` 序列化方法，不依赖任何外部包。
- `repositories/`：以 `abstract class` 形式声明仓储契约（PodcastRepository、FavoriteRepository、QueueRepository、SearchHistoryRepository），向上暴露领域操作（订阅、搜索、播放队列、收藏、历史记录），向下由 data 层实现；其中 PodcastRepository 还通过 `refreshPodcastFeed` / `refreshAllFeeds` 返回 `FeedRefreshResult` / `BatchRefreshResult` 与 `data/services/feed_refresh_service.dart` 耦合。
- `usecases/`：每个文件对应一个单一业务动作（如 GetPodcastByIdUseCase、AddToQueueUseCase），通过构造函数注入对应的 Repository，并在 `call()` 中执行参数校验与异常包装，再委托给仓储。
依赖方向单向：usecases → repositories → entities，domain 层不反向依赖 data 或 presentation。
