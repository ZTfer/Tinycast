- 服务类统一采用私有构造函数 + static final _instance + static get instance 的单例模式暴露实例。
- 异步操作通过 StreamController.broadcast() 暴露 Stream 接口供 UI 订阅，并在异常路径使用 Logger.error/warning/info 分级记录日志。
- 网络请求统一使用 Dio，超时和重试参数从 AppConstants 读取，错误通过 NetworkErrorHandler 或 AppException 包装抛出。
- 文件路径通过 FileStorageService 统一管理（getAudioDirectory/getImagesDirectory/generateAudioFileName 等），避免在业务代码中拼接路径。
- 数据库写入统一包裹在 IsarService.isar.writeTxn(() async {...}) 事务中，保证读写一致性。
- 对外返回结果使用不可变数据类（如 FeedRefreshResult、BatchRefreshResult、PodcastMergeResult、PlaybackProgress）而非 Map。
