该模块是 Flutter 展示层的一个 Feature 目录，采用按功能划分的目录结构：`favorite.dart` 作为入口 `ConsumerWidget`，负责监听 `favoriteEpisodesProvider` 和 `favoriteEpisodesLoadingProvider`，根据加载状态显示 CircularProgressIndicator 或空状态页，有数据时渲染 `ListView.builder` + `EpisodeItem`；`favorite_empty_page/` 子目录封装空状态 UI，拆分为 `FavoriteEmptyPage`（布局容器）和 `FavoriteEmptyInfo`（占位图与提示文案），遵循小组件拆分原则。业务交互通过 `ref.read(...).notifier` 调用跨 feature 的 `playbackProvider`、`navigationProvider` 以及 `getPodcastByIdUseCaseProvider`，依赖方向单向指向 presentation/providers 和 shared usecase providers，不直接依赖 domain 层。
