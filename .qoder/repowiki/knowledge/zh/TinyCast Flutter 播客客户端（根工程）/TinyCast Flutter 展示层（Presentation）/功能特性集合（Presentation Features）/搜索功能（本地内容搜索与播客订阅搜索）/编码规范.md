- 状态管理统一使用 Riverpod 的 NotifierProvider 模式：定义 State 类 + copyWith 方法 + Notifier 子类 + 顶层 Provider 暴露 state 切片（如 searchStateProvider、searchHistoryProvider）。
- UI 组件优先使用 ConsumerWidget，需要生命周期时再用 ConsumerStatefulWidget，通过 ref.watch 订阅状态、ref.read(notifier) 触发变更，保持纯函数式 build。
- 跨层依赖通过 Provider 注入：repository 和 usecase 均在对应 provider 中实例化并组合，避免在 notifier 中直接 new 依赖对象。
- 异步操作统一使用 try/catch 包裹，失败时设置错误状态或空数据，保证 UI 始终可渲染。
- 键盘导航通过 FocusNode.onKeyEvent 监听 arrowUp/arrowDown/enter，配合 selectedIndex 实现统一的列表选择与确认流程。
