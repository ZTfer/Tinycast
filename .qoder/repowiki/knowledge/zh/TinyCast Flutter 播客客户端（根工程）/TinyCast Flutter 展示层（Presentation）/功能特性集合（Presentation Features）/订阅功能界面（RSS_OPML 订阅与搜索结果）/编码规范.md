- Riverpod 状态通过 `ref.watch` / `ref.read(provider.notifier).method()` 在 `ConsumerWidget` / `ConsumerStatefulWidget` 中访问，避免直接持有 Provider 引用。
- 页面级组件统一采用 `const key` + `super.key` 的构造函数写法，静态子组件以 `const` 构造传递以提升性能。
- UI 颜色与尺寸使用硬编码的 `Color(0x...)` 与固定数值（如 12.0、80.0、16.0），未抽取到主题或常量文件中。
- 每个功能子目录以单一职责拆分（rss、opml、search_result、tab、action_bar），并通过相对路径 import 组合，保持模块内低耦合。
