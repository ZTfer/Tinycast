本模块是 Flutter 应用的前端展示层，采用三层协作结构：
- `widgets/` 提供原子-分子-有机体分层的可复用 UI 组件，被所有 Feature 共享。
- `providers/` 基于 Riverpod 封装播放、队列、收藏、设置、播客等业务的 Notifier/AsyncNotifier，作为各 Feature 的状态源。
- `features/` 按业务领域划分独立页面与子组件，每个 Feature 通过 `NavigationProvider` 路由导航，并消费对应 Provider 获取数据。
- `dialogs/toast/` 提供全局提示弹窗，被各 Feature 统一调用。
三者之间通过 Provider 订阅关系解耦：Feature 只依赖 widgets 和 providers，不直接互相引用，由顶层应用组装路由与 ProviderScope。
