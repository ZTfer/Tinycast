- 原子组件统一采用 StatelessWidget 或 StatefulWidget + private State class 形式，构造函数使用 const 构造并声明 required/可选参数默认值。
- 交互态（hover/press）通过 MouseRegion + GestureDetector 配合 _isHovering/_isPressed 布尔字段驱动 AnimatedContainer 背景色切换。
- 需要读取全局状态的 widget 使用 ConsumerWidget 并通过 ref.watch/ref.read 访问 Riverpod provider，而非传入回调。
- 错误提示组件（dialog/toast）提供静态 show() 方法封装 showDialog/OverlayEntry，调用方只需传入 context 和消息即可弹出。
- Organism 内部按功能职责拆分子目录（如 mini_player 下 episode_control_bar、volume_control_bar），每个子目录包含对应 dart 文件。
