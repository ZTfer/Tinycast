# Queue 测试

Queue由「队列」跟「继续播放」组成，每个组件由episode_item.dart来构建

## 列表样式

### 数据展示

#### 封面图：展示podcast封面图

1. 如果本地不存在：
  1. 先展示占位符
  2. 异步下载封面图，下载完成后展示对应的封面图片，并且将封面图目录保存到数据库中
2. 如果本地存在：直接展示对应的封面图，本地图片路径可以在podcast数据库中找到

#### 时间

pubdate 相对于当前展示时间：
1. 小于60秒，展示xx秒前
2. 小于60分，展示xx分前
3. 小于24小时，展示xx小时前
4. 小于7天，展示xx天前
5. 大于等于7天以上，展示具体的年月日，格式为年/月/日

#### 标题

展示episode的标题，Hover后展示下拉菜单，点击后进入episode详情

#### 简介

使用xx预先处理下HTML标签，展示处理后的纯文本，最多展示三行，没有数据时不展示

#### toolbar

##### play按钮

1. 展示当前episode的时长
2. 播放按钮图标
  1. 如果是未播放状态，展示播放图标
  2. 如果是播放状态，展示暂停图标

##### 下载状态图标

下载图标展示：
1. 通过检查数据库中是否有音频文件路径，判断对应的episode音频文件是否下载
  1. 如果没有下载，不展示下载图标
  2. 如果已经下载，展示下载图标
2. 如果是正在下载状态，展示下载进度，下载完成后展示下载图标

### 队列

如果队列中没有数据，则不展示对应的模块

### 继续播放

如果继续播放中没有数据，则不展示对应的模块
继续播放数据来源：lazyload展示所有的未播放episode

## 音频播放

### 根据设置继续播放或者暂停

如果播放的音频在队列中，根据设置中的选项：
1. 如果是「单集结束后继续播放」
  1. 如果队列中还有数据，则继续播放队列中的下一条
  2. 如果队列中没有数据
    1. 如果继续播放中还有数据，则播放继续播放列表中的内容
    2. 如果继续播放中没有数据，则暂停播放
2. 如果是「单集结束后停止」，则暂停播放

### 播放完episode后要能够更新历史记录

播放episode结束后需要在播放历史记录数据库中有对应的记录，能够更新历史记录UI的展示，点击Sidebar中的历史记录按钮时，在列表中要能够展示所有的播放记录列表


## 空页面

当队列跟继续播放没有数据时，展示空页面
