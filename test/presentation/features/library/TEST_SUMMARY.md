## 已知问题

### 布局溢出问题 (非关键)
**问题描述**: 部分测试中出现 RenderFlex 溢出 7.5 像素的警告

**影响范围**:
- Library Widget 的 Provider 集成测试中的3个测试
- 仅影响UI布局，不影响核心功能

**根本原因**:
- LibraryEmptyButton 组件中的 Row 布局在小屏幕尺寸下溢出
- 测试环境使用默认的小屏幕尺寸

**建议修复**:
```dart
// 在 LibraryEmptyButton 的 Row 中使用 Expanded 或 Flexible
Row(
  children: [
    Expanded(child: Text(...)), // 使用 Expanded 包裹文本
    Icon(...),
  ],
)
```

**优先级**: 低 (不影响功能，仅影响极端布局情况)
