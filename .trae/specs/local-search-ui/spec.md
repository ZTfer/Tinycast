# 本地搜索 UI/UX Spec

## 为什么

用户需要快速搜索本地资料库中的播客和剧集内容，并通过键盘快捷键和鼠标交互高效浏览搜索结果。系统应提供完整的搜索状态管理、搜索历史记录和流畅的键盘导航体验。

## 变更内容

- 创建 SearchHistory Isar 模型用于存储搜索历史
- 实现搜索状态管理（默认状态、搜索历史状态、搜索结果状态、空结果状态）
- 实现搜索历史管理（保存、获取、清空）
- 实现本地资料库搜索（播客标题/简介、剧集标题/简介）
- 实现键盘导航（上下箭头切换、Enter 确认）
- 实现鼠标 hover 交互
- 实现搜索结果跳转（播客详情、剧集详情）

## 影响

- 受影响的规格：无
- 受影响的代码：
  - Data 层：新增 `SearchHistory` 模型、`SearchHistoryRepository`
  - Domain 层：新增搜索相关 UseCases
  - Presentation 层：更新 `SearchPage`、`SearchInput`、搜索结果组件、新增 `SearchProvider`

## 新增需求

### 需求：搜索状态展示

系统应根据不同状态展示对应的 UI 组件。

#### 场景：默认状态

- **当**用户打开搜索页面且无搜索历史
- **则**只展示搜索输入框
- **并且**不展示 toolbar

#### 场景：有搜索历史状态

- **当**用户打开搜索页面且有搜索历史
- **则**展示搜索输入框
- **并且**展示搜索历史列表
- **并且**展示 toolbar

#### 场景：有搜索结果状态

- **当**用户执行搜索且有匹配结果
- **则**展示搜索输入框
- **并且**展示搜索结果列表（播客优先，剧集其次）
- **并且**展示 toolbar

#### 场景：无搜索结果状态

- **当**用户执行搜索但无匹配结果
- **则**展示搜索输入框
- **并且**展示空结果页面
- **并且**不展示 toolbar

### 需求：搜索历史管理

系统应使用 Isar 数据库管理搜索历史。

#### 场景：保存搜索历史

- **当**用户输入关键词并发起搜索
- **则**系统应保存关键词和搜索时间到 Isar 数据库
- **并且**按搜索时间倒序排列

#### 场景：获取搜索历史

- **当**用户打开搜索页面
- **则**系统应从 Isar 数据库获取搜索历史列表
- **并且**按搜索时间倒序展示

#### 场景：清空搜索历史

- **当**用户点击 toolbar 中的"清空记录"按钮
- **则**系统应删除所有搜索历史记录
- **并且**更新 UI 状态

### 需求：搜索历史交互

系统应提供搜索历史的交互功能。

#### 场景：键盘导航搜索历史

- **当**搜索历史列表展示时
- **并且**用户按上下箭头键
- **则**系统应切换选中的历史记录项
- **并且**选中样式与 hover 样式一致

#### 场景：鼠标 hover 搜索历史

- **当**鼠标悬停在搜索历史项上
- **则**系统应切换选中状态到该历史记录项

#### 场景：选择搜索历史

- **当**用户按 Enter 键或点击搜索历史项
- **则**系统应以该关键词进行搜索

### 需求：本地资料库搜索

系统应支持搜索本地资料库内容。

#### 场景：搜索播客

- **当**用户输入搜索关键词
- **则**系统应匹配播客标题和播客简介
- **并且**返回匹配的播客列表

#### 场景：搜索剧集

- **当**用户输入搜索关键词
- **则**系统应匹配剧集标题和剧集简介
- **并且**返回匹配的剧集列表

#### 场景：搜索结果排序

- **当**搜索结果返回
- **则**播客结果应优先展示
- **并且**剧集结果在播客结果之后展示

### 需求：搜索结果交互

系统应提供搜索结果的交互功能。

#### 场景：键盘导航搜索结果

- **当**搜索结果列表展示时
- **并且**用户按上下箭头键
- **则**系统应切换选中的搜索结果项
- **并且**选中样式与 hover 样式一致

#### 场景：鼠标 hover 搜索结果

- **当**鼠标悬停在搜索结果项上
- **则**系统应切换选中状态到该搜索结果项

#### 场景：选择播客搜索结果

- **当**用户按 Enter 键或点击播客搜索结果
- **则**系统应跳转到播客详情页面

#### 场景：选择剧集搜索结果

- **当**用户按 Enter 键或点击剧集搜索结果
- **则**系统应跳转到剧集详情页面

## 修改的需求

无

## 移除的需求
