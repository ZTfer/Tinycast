# 搜索功能 Spec

## 为什么

用户需要搜索播客以发现新的内容。系统应提供搜索功能，包括搜索播客目录和搜索本地资料库。

## 变更内容

- 实现搜索服务
- 实现搜索结果展示
- 实现搜索历史管理
- 实现搜索 UI 交互

## 影响

- 受影响的规格：RSS 订阅
- 受影响的代码：Data 层（datasources、repositories）、Domain 层（usecases）、Presentation 层（providers、pages）

## 新增需求

### 需求：播客目录搜索

系统应支持搜索播客目录。

#### 场景：搜索播客

- **当**用户输入搜索关键词
- **则**系统应搜索播客目录（如 Podcast Index）
- **并且**显示搜索结果
- **并且**支持分页

#### 场景：搜索结果展示

- **当**搜索结果返回
- **则**应显示播客列表
- **并且**显示播客信息（封面、标题、作者）
- **并且**提供订阅按钮

#### 场景：从搜索结果订阅

- **当**用户从搜索结果订阅播客
- **则**系统应调用 RSS 订阅功能
- **并且**显示订阅进度
- **并且**订阅成功后更新列表

### 需求：本地资料库搜索

系统应支持搜索本地资料库。

#### 场景：搜索本地播客

- **当**用户在资料库页面搜索
- **则**系统应搜索已订阅播客
- **并且**过滤显示结果
- **并且**支持实时搜索

#### 场景：搜索本地节目

- **当**用户在节目列表中搜索
- **则**系统应搜索节目标题和描述
- **并且**过滤显示结果
- **并且**支持实时搜索

### 需求：搜索历史

系统应管理搜索历史。

#### 场景：保存搜索历史

- **当**用户执行搜索
- **则**系统应保存搜索关键词
- **并且**限制历史记录数量
- **并且**去重

#### 场景：显示搜索历史

- **当**用户点击搜索框
- **则**应显示搜索历史
- **并且**允许快速选择历史搜索
- **并且**提供清除历史选项

#### 场景：清除搜索历史

- **当**用户清除搜索历史
- **则**系统应删除所有历史记录
- **并且**更新显示

### 需求：搜索 UI 交互

系统应提供友好的搜索 UI。

#### 场景：搜索输入

- **当**用户输入搜索关键词
- **则**应支持实时搜索
- **并且**显示加载状态
- **并且**支持清除输入

#### 场景：搜索结果交互

- **当**用户点击搜索结果
- **则**应显示播客详情
- **或者**直接订阅播客

#### 场景：空搜索结果

- **当**搜索无结果
- **则**应显示空状态提示
- **并且**提供搜索建议

### 需求：搜索错误处理

系统应优雅地处理搜索错误。

#### 场景：网络错误

- **当**搜索请求失败
- **则**应显示网络错误提示
- **并且**提供重试选项

#### 场景：API 错误

- **当**搜索 API 返回错误
- **则**应显示错误提示
- **并且**记录错误日志

无

## 移除的需求
