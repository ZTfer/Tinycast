# 设置管理功能 Spec

## 为什么

用户需要配置应用偏好设置，包括播放设置、下载设置、常规设置等。系统应提供友好的设置界面，并持久化用户设置。

## 变更内容

- 实现设置数据模型
- 实现设置管理逻辑
- 实现设置 UI 交互
- 实现设置持久化

## 影响

- 受影响的规格：所有功能模块
- 受影响的代码：Data 层（models、repositories）、Domain 层（entities、repositories、usecases）、Presentation 层（providers、pages）

## 新增需求

### 需求：设置数据模型

系统应定义设置的数据模型。

#### 场景：设置模型定义

- **当**定义设置模型
- **则**应包含以下字段：
  - playbackSpeed: double（播放速度）
  - skipForwardTime: int（快进时间，秒）
  - skipBackwardTime: int（快退时间，秒）
  - continuousPlay: bool（连续播放）
  - autoDownload: bool（自动下载）
  - downloadOnWifiOnly: bool（仅 WiFi 下载）
  - downloadFavoritesOnly: bool（仅下载收藏）
  - removePlayedDownloads: bool（移除已播放下载）
  - theme: String（主题）
  - language: String（语言）

### 需求：播放设置

系统应提供播放设置。

#### 场景：播放速度设置

- **当**用户选择播放速度
- **则**系统应保存播放速度
- **并且**更新播放器
- **并且**更新设置显示

#### 场景：跳转时间设置

- **当**用户设置跳转时间
- **则**系统应保存快进/快退时间
- **并且**更新播放控制
- **并且**更新设置显示

#### 场景：连续播放设置

- **当**用户启用/禁用连续播放
- **则**系统应保存连续播放偏好
- **并且**更新播放逻辑
- **并且**更新设置显示

### 需求：下载设置

系统应提供下载设置。

#### 场景：自动下载设置

- **当**用户启用/禁用自动下载
- **则**系统应保存自动下载偏好
- **并且**更新下载逻辑
- **并且**更新设置显示

#### 场景：WiFi 下载设置

- **当**用户启用/禁用仅 WiFi 下载
- **则**系统应保存 WiFi 下载偏好
- **并且**更新下载逻辑
- **并且**更新设置显示

#### 场景：仅下载收藏设置

- **当**用户启用/禁用仅下载收藏
- **则**系统应保存仅下载收藏偏好
- **并且**更新下载逻辑
- **并且**更新设置显示

#### 场景：移除已播放下载设置

- **当**用户启用/禁用移除已播放下载
- **则**系统应保存移除偏好
- **并且**更新下载逻辑
- **并且**更新设置显示

### 需求：常规设置

系统应提供常规设置。

#### 场景：主题设置

- **当**用户选择主题
- **则**系统应保存主题偏好
- **并且**应用主题
- **并且**更新设置显示

#### 场景：语言设置

- **当**用户选择语言
- **则**系统应保存语言偏好
- **并且**应用语言
- **并且**更新设置显示

### 需求：设置持久化

系统应持久化用户设置。

#### 场景：保存设置

- **当**设置发生变化
- **则**系统应保存所有设置到数据库
- **并且**立即生效

#### 场景：恢复设置

- **当**应用启动
- **则**系统应从数据库加载设置
- **并且**应用设置
- **并且**更新设置显示

### 需求：设置 UI 交互

系统应提供友好的设置 UI。

#### 场景：设置页面导航

- **当**用户进入设置页面
- **则**应显示设置标签页
- **并且**允许切换不同设置类别

#### 场景：设置项交互

- **当**用户更改设置
- **则**应立即保存设置
- **并且**显示保存成功提示
- **并且**更新相关功能
